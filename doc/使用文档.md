# PS 图层导出工具 — 使用文档

## 一、安装

### 自动安装（推荐）

- **Windows**: 双击运行 `com.ps.export.layer.tool-installer.exe`
- **macOS**（二选一）：
  - **双击运行** `com.ps.export.layer.tool-installer.command`（自动打开终端执行）
  - **终端运行** `com.ps.export.layer.tool-installer.sh`（无需执行权限）：
    ```bash
    bash com.ps.export.layer.tool-installer.sh
    ```

> 提示：macOS 下载的脚本若被 Gatekeeper 拦截（提示"无法验证开发者"），可右键 → 打开运行一次，或先执行 `xattr -d com.apple.quarantine <文件名>` 清除隔离标记后重试。

安装程序会自动：
1. 检测 Photoshop 安装（仅提示）
2. 复制插件文件到 CEP 扩展目录（`CSXS/`、`dist/`、`doc/`）
3. 保留用户自定义预设（`dist/lib/presets/`），覆盖安装不会丢失
4. 开启 CEP 调试模式（CSXS 6-12）

**卸载方法**：
- **Windows**: 双击运行 `com.ps.export.layer.tool-uninstaller.exe`
- **macOS**: 双击 `com.ps.export.layer.tool-uninstaller.command`，或终端 `bash com.ps.export.layer.tool-uninstaller.sh`

卸载时会把用户预设备份到 `com.ps.export.layer.tool_user_files/`，下次安装自动恢复。

安装后重启 Photoshop，菜单：**窗口 → 扩展功能 → PS 图层导出工具**。

### 手动安装（zip 包）

解压 `com.ps.export.layer.tool-vX.X.X.zip`，将文件夹复制到：

- **Windows**: `%APPDATA%\Adobe\CEP\extensions\`
- **macOS**: `~/Library/Application Support/Adobe/CEP/extensions/`

然后启用调试模式（运行 `doc/csxs.reg` 中的注册表文件或执行 `defaults write com.adobe.CSXS.11 PlayerDebugMode 1`）。

### 兼容性

- Photoshop 2019 (v20.0) 及以上
- Windows / macOS

## 二、功能概览

插件有三个标签页：

- **文字导出**：选中 PS 文本图层，将每个字符导出为独立 PNG/JPG 素材，宽高可分别选择「统一尺寸」或「按内容裁剪」，对齐基准也可分「水平 / 垂直」选排印框或墨迹。典型场景：导出数字 0-9、时间符号、日期分隔符、星期文字、天干地支、星座名等，用于游戏/应用的 UI 素材制作。
- **统一导出**：选中多个图层，每个图层导出为独立图片，统一画布尺寸和对齐方式。
- **自由导出**：选中多个图层，每个图层保留原始尺寸独立导出，支持四方向边距配置。

## 三、使用步骤

### 1. 选中文本图层

在 PS 中选中一个文本图层，面板自动读取字体、字号、颜色等信息。

### 2. 选择预设

面板底部「预设」区域提供 22 个内置预设：

| 分类 | 预设示例 |
|------|---------|
| 数字 | 0-9 |
| 时间 | 0-9 + : - / 时分秒（数字符号 / 中文） |
| 日期 | 0-9 + . - / 年月日（数字符号 / 中文） |
| 周 | 星期日-六 / 周日-六 / Sun-Sat / SUN-SAT（8 种风格） |
| 天干地支 | 甲乙丙丁… / 子丑寅卯… |
| 生肖 | 鼠牛虎兔… |
| 时辰 | 子时丑时… |
| 农历 | 正月-腊月 / 正-腊（全称/单字）/ 初一到三十 + 闰 |
| 其他 | 零壹贰…大写数字 / 白羊座-双鱼座 |

点击预设卡片自动填充导出项列表和表单配置。

### 3. 编辑导出项

预设填充后可手动编辑每行的「渲染内容」和「文件后缀」，并通过「宽」「高」两个勾选框控制该字符在**每个轴**上是否参与统一画布：

- **渲染内容**：PS 中实际渲染的文字（如"星期日"）
- **文件后缀**：导出文件名的标识部分（如 `1` → `week_1.png`）
- **宽 / 高**：勾选 = 该轴使用统一画布尺寸；不勾选 = 该轴按内容裁剪

两个轴互相独立，可任意组合：

| 勾选情况 | 效果 |
|---------|------|
| 宽高都勾选 | 所有切图同尺寸（原行为） |
| 只勾选宽 | 宽度全部一致，高度各自贴合字符内容，去除上下空白 |
| 只勾选高 | 高度全部一致，宽度各自贴合字符内容，去除左右空白 |
| 都不勾选 | 每张切图都贴合自身内容尺寸（最省像素） |

裁剪轴的实际尺寸 = 内容尺寸（向上取整）+ 画布延长 + 该轴两侧的对齐边距。
例如日期类文本「8月24日」，「月」「日」较宽、数字较窄，取消勾选宽即可让数字切图不再带大量透明空白。

> **注意**：某轴不勾选时，该轴上的锚点几乎不起作用 —— 画布已贴合内容，只剩「对齐边距」这点空间。

空后缀自动用渲染内容作为文件名。点击 **+ 添加行** 增加新项，每行可单独删除。

### 4. 配置导出参数

| 参数 | 说明 |
|------|------|
| 文件名前缀 | 如 `time_` → `time_0.png` |
| 画布尺寸 | 自动检测（含延长）或手动输入 |
| 对齐方式 | 9 点锚位（↖↑↗←⊙→↙↓↘） |
| **水平基准** | `排印框` = 按字宽定位（等字宽素材的共有字形同 x，如「周X」里的「周」）；`墨迹` = 按各项可见像素定位（每张内容横向居中，共有字形 x 会随墨迹宽变化） |
| **垂直基准** | `排印框` = 整组基线一致（墨迹高矮不一的项会显得偏心）；`墨迹` = 每张内容纵向居中（高矮不一则基线错开） |
| 对齐边距 | 四方向独立（上/右/下/左），锚点对齐后图层与画布边缘的额外距离，默认 0 |
| 导出格式 | PNG / JPG |
| 导出目录 | 默认 PSD 所在目录下的 `output/` 文件夹 |

两个基准默认为 **水平「墨迹」+ 垂直「排印框」**，即「每张内容横向居中、整组基线一致」。怎么选：

- 同一批素材里有**共有字形**（周X、星期X、日期-中文…），希望它们在每张图里落在同一位置 → 水平基准选「排印框」；
- 素材是**单项或字宽各不相同**（数字、天干、生肖、英文周、日期-数字符号…），希望每张都居中 → 水平基准留「墨迹」；
- 希望七张放在一起**像同一行文字**（基线一致）→ 垂直基准留「排印框」；希望每张小符号（如 `.` `-`）也各自居中 → 垂直基准改「墨迹」（代价是基线不再对齐）。

> **一个物理限制**：统一画布下「每张可见内容居中」与「共有字形落在同一 x」二者不可兼得（后者要求每张画布宽度不同）。两者都要的话，把该轴的「宽」**取消勾选**（按内容裁剪）+ 左右对齐边距设成相等即可。

勾选框存在两项时，画布预览会**分轴**显示：某一轴没有任何项参与统一时，该轴显示「按内容裁剪」。

### 5. 导出

点击 **开始导出**。自动模式下先测量每个字符的宽高，按各轴是否参与统一计算画布尺寸，再逐字符导出。

---

### 自由导出（Tab 3）

选中多个图层，每个图层保留原始尺寸独立导出。

**配置参数**：

| 参数 | 说明 |
|------|------|
| 导出文件名 | 表格中每行可编辑，默认 = 图层名，自动处理非法字符和命名冲突 |
| 四方向边距 | 上/右/下/左 独立设置（默认 2px） |
| 导出格式 | PNG / JPG |
| 导出目录 | 与其他 Tab 共享 |

**图层列表**：支持正序/倒序切换、行数调节。图层组自动跳过。

## 四、预设管理

### 保存预设

1. 编辑好导出项和配置（含每行的「宽 / 高」勾选）
2. 在顶部「预设名称」输入框填写名称
3. 点击 **保存为预设**，预设卡片添加到列表底部

> **勾选的持久化时机**：勾选框只改当前表单，**不会自动写盘**；只有点击「保存为预设」时才会写入预设文件。

### 修改预设

1. 点击预设卡片 → 配置填充到表单
2. 修改后名称不变 → 点保存 → 覆盖原预设
3. 修改名称 → 点保存 → 创建新预设

### 删除预设

点击卡片右上角 × 按钮。

### 拖拽排序

按住预设卡片拖到目标位置松手，顺序自动保存。

### 预览

开启「预览」开关，鼠标悬停卡片上方显示配置摘要（前缀/格式/对齐/边距/导出项）。若预设中有字符不参与统一，预览会额外显示「分轴: N 项裁剪宽，M 项裁剪高」。

### 自动导出

开启「应用后自动导出」开关，点击预设卡片自动完成检测尺寸 + 导出。

## 五、自定义预设数据

预设存储在 `dist/lib/presets/default.json`，可直接编辑此文件批量修改预设配置：

```json
{
  "id": "builtin-number-0-9",
  "name": "数字",
  "items": [
    { "text": "0", "name": "0", "unifyWidth": true, "unifyHeight": true },
    { "text": "1", "name": "1", "unifyWidth": true, "unifyHeight": false }
  ],
  "prefix": "num_",
  "format": "png",
  "anchor": "middle-center",
  "alignModeX": "ink",
  "alignModeY": "layout",
  "paddingW": 10,
  "paddingH": 10
}
```

- `unifyWidth` / `unifyHeight`：该字符的宽/高是否参与统一画布。`true` = 统一，`false` = 按内容裁剪。
- **两个字段可以省略**：省略时一律按 `true`（参与统一）处理，因此旧预设文件无需修改即可继续使用。
- `alignModeX` / `alignModeY`：水平/垂直对齐基准，取值 `"layout"`（排印框）或 `"ink"`（墨迹）。
- **这两个字段也可以省略**：全部省略时按「水平 `ink` + 垂直 `layout`」处理（与面板默认一致），所以旧预设文件同样无需修改。个别预设想单独指定就写上去。

修改后重启面板即可生效。更新插件时预设文件会自动保留。

## 六、常见问题

### macOS 安装脚本双击没反应 / 提示"无法验证开发者"

下载的脚本带有 macOS 隔离标记（quarantine），执行位也可能在下载过程中丢失。三选一：

1. 右键点击脚本 → **打开** → 弹窗中再点一次「打开」（一次性放行）
2. 清除隔离标记：`xattr -d com.apple.quarantine com.ps.export.layer.tool-installer.command`
3. 改用终端运行（不依赖执行位）：`bash com.ps.export.layer.tool-installer.sh`

安装脚本在终端里会打印进度，看到「安装完成！」且预览里没有 `[错误]` 即为成功。

### 面板白屏

CEP 调试模式未启用。运行 `doc/csxs.reg`（Windows）或执行 `defaults write com.adobe.CSXS.11 PlayerDebugMode 1`（macOS），重启 PS。

### "未打开文档"

在 PS 中打开一个 PSD 文件并选中文本图层。

### 导出的素材被裁切

导出引擎已从 Save for Web 切换为 PS 主渲染引擎，裁切问题已从根本上修复。如仍有问题，请检查边距值（默认 10px）是否足够。

### 预设文件被覆盖

更新插件时安装脚本会自动备份和恢复 `dist/lib/presets/` 目录。如仍丢失，检查 `_user_files` 备份目录。

> 注意：`dist/lib/presets/default.json` 同时被用作「内置预设种子」和「面板保存预设的落盘文件」，因此**在开发环境执行 `npm run build` / `npm run package` 会用种子覆盖面板里保存的预设**（安装/升级路径不受影响）。

### 预设全部消失

检查 `dist/lib/presets/default.json` 是否存在。如被误删，可重新构建插件恢复内置预设，或从备份恢复。

### 导出的图是空白的（全透明）

插件已修复该问题（根因：复制的图层继承模板层的隐藏状态，隐藏图层不参与导出渲染）。如果仍出现空白图，请先重启 Photoshop —— 宿主脚本被引用后无法热更新，旧的缓存脚本可能仍在运行。

### 改了代码但导出结果没变化

宿主脚本被 PS 引用后不会热更新：改动宿主代码后必须**重启 Photoshop**，否则仍在运行缓存的旧脚本。面板改动只需刷新面板。

### 勾选了「宽 / 高」但没保存下来

这是设计行为：勾选框只修改当前表单，不会自动写入预设文件。要让勾选持久化，请点击 **保存为预设**。旧预设文件里没有 `unifyWidth` / `unifyHeight` 字段时，一律按「参与统一」处理，不影响使用。

### 同一批素材里「周」的位置对不齐（共有字形不在同一位置）

这是**水平基准**的选择问题：`墨迹` 让每张内容各自横向居中，共有字形（如「周X」里的「周」）的位置就会随第二个字的墨迹宽变化。想让共有字形落在同一 x → 把**水平基准**改成 `排印框`。

### 数字、句点等切图偏右或贴到边缘

两个已知原因都已修复：① 文字图层带图层效果（描边/投影）或负字距时，可见墨迹比字宽宽，按字宽盒居中会把内容推向一侧 —— 现在参考宽取 `max(字宽, 墨迹宽)`；② 居中偏移为负时被错误钳制到 0、内容被钉在左边 —— 现在统一轴只在画布装不下内容时才钳制。若你的旧导出结果仍有此现象，重启 PS 后重新导出即可。

### 同一批素材基线不齐（高矮不一的项错行）

这是**垂直基准**的选择问题：`墨迹` 让每张内容各自纵向居中，墨迹高矮不一的项就会错行。要「同一行」→ 把**垂直基准**保持/改成 `排印框`（整组共用同一个偏移，基线一致）；代价是墨迹明显偏矮或偏高的项会显得偏心。

### 想让共有字形固定、同时每张内容也居中

统一画布下两者不可兼得。把该轴的「宽」**取消勾选**（按内容裁剪），并把左右对齐边距设成相等 —— 这样共有字形钉在左边距位置、内容也是居中的，代价是每张画布宽度不同（不再统一）。
