## 概述

新增「批量导出」tab：选中 PS 文本图层后，将每个字符（如 0-9、冒号）一键导出为统一画布尺寸的 web 素材（PNG/JPG）。

## 关键设计决策

### 宿主脚本：raw ActionManager
batchExport.ts 全部使用原始 ActionManager 和 ps-api `index.ts` 统一导入，不引入新的子路径依赖（从 `lib/` 子路径单独导入会导致 webpack 模块冲突，hostscript 全部报 `EvalScript error`）。详见 CLAUDE.md「ps-api 导入统一入口」。

### 两阶段测量+导出
- Phase 1：在 2000×2000 透明文档中逐字符 paint → `boundsNoEffects()` → 记录 → remove
- Phase 2：`resizeCanvas` 到最终尺寸 → 逐字符 paint → translate（按锚点） → exportToWeb → remove
- 单文档复用，不创建多个临时文档

### 面板轮询
- 有文档时 1s 轮询检测选中图层
- 无文档时停止，点击「重新检测」或「开始导出」自动恢复
- 切换到其他 tab 时 v-if 销毁组件，停止轮询

### 锚点偏移计算
使用 `boundsNoEffects` 度量 + ActionManager `move` translate，确保同一字体不同字符基线对齐。
