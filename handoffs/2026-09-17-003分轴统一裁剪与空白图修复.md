## 关键决策

- **持久化只发生在「保存为预设」**：
  - 原因：你明确要求「不要勾选更新了，只在用户点击保存预设时才会持久化」
  - 影响：`setItemUnify` 只改表单、不写盘；曾实现过的 `syncActivePreset()` 与 `watch(activePresetId)` 自动写回已**全部删除**，勿重新引入
- **分轴语义（取消勾选 = 按内容裁剪）**：两轴完全独立、允许任意组合（宽统一+高裁剪等），不做行级互斥，也不做「勾一个自动取消另一个」
- **裁剪轴复用 `paddingW/H` + 四方向对齐边距**：不新增独立边距配置；裁剪轴上锚点退化为钳制边界（内容+边距刚好占满画布，无松弛空间）
- **裁剪轴画布用 `Math.ceil` 口径**：与既有测量口径一致，保证内容不被裁切
- **空白图修复采取保守路线**：把实验性的 `duplicateLayerById` / `getBoundsById` / `removeLayerById`（裸 ActionManager）从导出主流程撤下，回到已验证的 `duplicateLayer()` + `layer.bounds()` + `layer.remove()` 图层句柄路径，另加可见性兜底。这三个工具函数**仍保留在 exportUtils.ts 但已无人调用**（下次可用 `npx tsc` 无警告确认），若确认不再需要可删

## 已知问题 / 注意事项

- **PS 里验证 bundle 的正确姿势**（本次摸出来，很有用）：把 `dist/jsx/hostscript.js` 以 **UTF-8 BOM** 另存一份副本，再用 `Photoshop.Application` COM 的 `DoJavaScriptFile` 执行一个 driver（driver 里 `$.evalFile(副本)` 后直接调 `$.HostScript.batchExport(JSON)`）。
  - **BOM 必须有**：无 BOM 的 UTF-8 会被 ExtendScript 按 ANSI 解析，中文串乱码 → `EVAL-ERR 类型错误: 无法转换`
  - 测试文档用 `zz_test_*` 命名，跑完按名关闭并删掉 `.ps-verify/` 沙箱；**绝不要动用户已打开的 PSD**
- **git 推送环境（未修复，下次会再踩）**：
  - 全局 `http.sslBackend` **未设置** → 走 Windows schannel → `schannel: AcquireCredentialsHandle failed: SEC_E_NO_CREDENTIALS`。实测 `-c http.sslBackend=openssl` 后可通
  - 全局 `http.proxy=http://127.0.0.1:7897` 是**好的够用**的；`https.proxy=https://127.0.0.1:7897` 写法不对（代理地址用 https 无意义），实测暂不影响
  - Windows 凭据管理器里 `git:https://github.com` 是**失效 token**；`gh auth login` 只刷新 `gh:` 条目，所以 git 仍报 `Invalid username or token`
  - 本次推送用一次性方案完成：`gh auth token` → 临时 `GIT_ASKPASS` 脚本（仅含 `echo <token>`）→ `git -c http.sslBackend=openssl push` → **推送后立即删除该临时文件**。token 未落盘、未回显，全局配置未改动
- **PowerShell 两个坑（本次踩过）**：
  - `$host` 是保留自动变量（大小写不敏感），赋值会失败并把后续路径变成 `System.Management.Automation...`，直接写坏文件名为 `System.Management.Automation.Internal.Host.InternalHost` 的空文件（已清理）
  - `(Resolve-Path '.').Path -replace '\\','/' + '/x'` 会被解析成 `-replace` 的三参数形式而报错；必须写 `((Resolve-Path '.').Path -replace '\\','/') + '/x'`
- **`.claude/skills/handoff` 是个同名文件**（不是目录），会遮蔽真正的 skill；handoff 的 skill 定义在 `.agents/skills/handoff/SKILL.md`
- **面板 / 宿主更新方式不同**：面板改动刷新面板即可；宿主脚本（`src/jsx/**`）改动**必须重启 PS**，否则跑的是缓存脚本
